Notes-to-self on allowing external users to register and use gitea
servers, c.a. 2021-12-05

* Goals
  - Let others use my gitea server

* Plan
  - Enable auto account registration
* Concerns/Security
  - People randomly creating accounts and doing bad things
    + addressed by =ENABLE_CAPTCHA= (see below)
    + =REGISTER_EMAIL_CONFIRM= is another option, but would require me
      t to set up outbound email (may happen in the future)

* Implementation

  Tweak the following in =/etc/gitea/gitea.ini= (or equivalent)
  
  #+begin_example
  ; -> https://docs.gitea.io/en-us/config-cheat-sheet/#service-service
[service]
DISABLE_REGISTRATION              = false
ENABLE_CAPTCHA                    = true
SHOW_REGISTRATION_BUTTON          = true
  #+end_example

  
  #+begin_example sh
  sudo systemctl restart gitea
  #+end_example
