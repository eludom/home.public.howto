* "Notes To Self" On Setting Up TOTP In KeePassXC

As part of my effort to "just turn it off" and get away from
dependency on the smart phone, I finally put in a little effort to
figure out how to use TOTP on Unix instead of, e.g., Google
Authenticator on my phone.


** TODO  Install zbarimg

   On Arch Linux, run the command:
   #+begin_src bash
  sudo pacman -S zbar
   #+end_src
   This installs the zbar image processing library, which allows you to read QR codes.

** TODO  Go to site/account/settings, initiate 2FA setup

   Navigate to the security settings of your account in your web
   browser and look for an option to enable two-factor authentication
   (2FA). Follow the prompts until a QR code is presented.


** TODO  Screen capture the QR code

   Use a screen capture tool to take a screenshot of
    the QR code displayed on the website.

** TODO  Decode the image

   Run the command below to extract the TOTP secret and other information from the captured QR code:
   #+begin_src bash
  zbarimg qr.png
   #+end_src
   Replace =qr.png= with the path to your saved QR code image.

** TODO  Extract the secret and algorithm

   Review the output from the previous command. The line will contain a
   URL-like string that includes the =secret=, =algorithm=, =digits=,
   and =period=. Note down the secret (usually a base32-encoded string)
   and the algorithm (e.g., SHA1).


** TODO  Add to entry in KeePass

   Open KeePassXC, locate the entry for the account you wish to enable
   TOTP for, and edit it. Look for an option to add a TOTP field (this
   can usually be found under the "TOTP" tab). Input the extracted
   secret and set the other parameters (if necessary). Ensure that the
   "TOTP" checkbox is enabled.

** TODO  Finish Setup

   Save your changes in KeePassXC. Use the TOTP generator feature in
   KeePass to generate a code. Then, go back to your account’s 2FA
   setup page, enter the generated code, and confirm it to finalize the
   TOTP setup.

*** TODO TEST Test TOTP functionality

   Log out of your account and attempt to log back in. Enter your
   username and password as usual, then input the TOTP code generated by
   KeePassXC. This will confirm that 2FA is correctly configured and
   working as intended. If successful, your setup is complete.
