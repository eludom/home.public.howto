* Intro
** What
  
 This is a HOWTO on installing/using FOO...

** Why
   - I want use ansible because I install a lot of things, and
     sometimes machines go down, I need to re-install, I forget what I
     did, etc.
   - Ansible is simple-ish (in concept) ... set up SSH on the clients
     and let the master push things out and insure the state is
     consistent.  No agents (puppet).  In practice, it looks like it's
     gotten complex and marketing has gotten involved :-(
    
** Where
   - I'm installing Ansible on my laptop (master) and Raspberry Pi
     (target) for starters.

** Who
   - I document things I learn/install mostly for myself so I won't
     have to re-learn them

* How

   - wikipedia :: https://en.wikipedia.org/wiki/Ansible_(software)
   - vendor intro :: https://docs.ansible.com/ansible/latest/user_guide/intro_getting_started.html
     
** I did this
*** Ansible install and setup
**** On the master
     
    - [ ] install using apt
      #+begin_example
      sudo apt-get install ansible
      #+end_example

    - [ ] re-install latest version using pip
       
      I originally installed using apt.   This pulled down 2.9.  I
      later re-installed form source (2.11) due to some
      incompatability

      #+begin_example
      python3 -m pip install ansible
      ansible --version
      #+end_example

    - [ ] Create an ansible user 

      #+begin_example
      sudo useradd ansible
      sudo passwd ansible
      sudo mkdir ~ansible
      sudo chown ansible.ansible ~ansible
      sudo passwd ansible
      ssh ansible@localhost
      #+end_example

    - [ ] Create a new SSH key

      Create a new .ssh public/private key pair to be used with
      ansible and copy it to the ansible target:

      #+begin_example
      ssh-keygen -t rsa -b 4096 -C "ansible@ed"


      ssh-copy-id -i ~/.ssh/id_rsa.pub hangout
      #+end_example

    - [ ] Set up the hosts file

      My =/etc/ansible/hosts= file looks like this

      #+begin_example
hangout.home

[ubuntu]
hangout.home
 [ubuntu:vars]
# ansible_private_key_file=/home/user/.ssh/id_rsa
# ansible_user=admin
 ansible_become=yes
 ansible_become_method=sudo
      #+end_example

      "hangout.home" is resolved via my local [[https://pi-hole.net/][Pi-hole DNS server]]
      pointing at my raspberry pi

**** On the client[s]
    - [ ] Create an ansible user 

      #+begin_example
      sudo useradd ansible
      sudo passwd ansible
      sudo mkdir ~ansible
      sudo chown ansible.ansible ~ansible
      sudo passwd ansible
      ssh ansible@localhost
      #+end_example

    - [ ] Create ~/.ssh/authorized_keys

      #+begin_example
      Copy ~/.ssh/id_rsa.pub (from the master) to
      ~/.ssh/authorized_keys to allow password-less logins

      OR

      ssh-copy-id -i ~/.ssh/id_rsa.pub hangout

      on the master
      #+end_example



**** Testing connectivity

     Test connectivity with =-m ping=

     #+begin_example
     $ ansible all -m ping

        "discovered_interpreter_python": "/usr/bin/python3"
    },
    "changed": false,
    "ping": "pong"
}
     #+end_example

     #+end_example

*** Playbook books
    
**** Create and run simple playbook to update ubuntu and run it

#+begin_example
$ cat <<EOF > playbooks/update-ubuntu2.yml 
> - hosts: ubuntu
>   tasks:
>     - name: Update cache 
>       apt:
>        update_cache: yes
>          
>     - name: Upgrade all packages on servers
>       apt: 
>         name: "*"
>         state: latest
> EOF

ansible-playbook playbooks/update-ubuntu.yml -i /etc/ansible/hosts 

#+end_example
